* **Interactive Hero Section:** A CSS-animated folder that opens on click to reveal my introduction.
* **Custom Cursor:** A JavaScript-powered star cursor with a fading trail effect.
* **Fully Responsive:** Optimized for desktop, tablet, and mobile viewing.
* **Scroll Animations:** Smooth fade-in reveal effects as the user scrolls down the page.
